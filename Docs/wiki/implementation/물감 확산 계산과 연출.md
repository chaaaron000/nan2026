# 물감 확산 계산과 연출

> Sources: NaN2026 현재 코드베이스, 2026-08-02; NaN2026 물감통 사용 예약 구현, 2026-08-04

> Updated: 2026-08-04

## Overview

현재 확산 시스템은 벽 기반 BFS가 불변 `PaintApplicationPlan`을 만들고, 커맨드가 모델의 최종 상태를 확정한 뒤 `PaintSpreadSequencePlayer`가 계획을 화면에 재생하는 3단계 구조다. 계산 결과에는 좌표뿐 아니라 최단 거리, 같은 거리로 들어온 모든 방향, 적용 전후 상태가 포함된다.

## 확산 계획 모델

```text
PaintApplicationPlan
└─ PaintSpreadWave (Distance)
   └─ PaintSpreadCellStep
      ├─ Position
      ├─ Distance
      ├─ IncomingDirections
      ├─ PreviousState
      └─ ResultState
```

배열을 복사하고 `ReadOnlyCollection`으로 노출하므로 실행과 연출이 같은 스냅샷을 공유하면서 외부에서 결과를 바꾸지 못한다. `PreviousState`는 Undo의 부분 스냅샷이고 `ResultState`는 모델 적용과 연출 완료 후 표시 값이다.

## BFS 계산

범위 N은 시작 셀을 거리 0으로 보고 최대 N-1칸 이동한다. `GridState.CanMove`가 외곽과 벽을 검사하며, 최초 방문 거리를 `int[]`에 기록한다. 더 긴 경로는 버리고 같은 최단 거리로 도착한 경우에는 `PaintIncomingDirection` 플래그를 OR해 여러 유입 방향을 보존한다.

각 거리의 좌표를 별도 목록에 쌓은 뒤 wave를 만든다. RGB는 이전 상태와 해당 비트를 OR하고, Clear는 결과를 Empty로 지정한다. 탐색 시간과 공간은 방문 셀 수에 선형이다.

## 커맨드와 모델 적용

`PaintBucketUseCommand.Execute`는 계획을 먼저 계산하고 물감통 소모에 성공하면 모든 `ResultState`를 `GridState`에 적용한다. 화면은 직접 바꾸지 않는다. 성공한 커맨드만 `CommandController`의 스택에 들어간다.

Undo는 계획의 모든 `PreviousState`를 `GridState`와 `GridView`에 즉시 복원하고 물감통을 되살린다. 예전의 별도 `PaintSnapshot` 목록 대신 CellStep 자체가 상태 스냅샷 역할을 한다.

## 화면 재생

RGB 물감은 거리 오름차순 wave마다 이펙트를 만들고 핵심 파티클 수명만큼 기다린 뒤 해당 wave의 View 결과를 적용한다. Clear는 거리별 전파 없이 모든 대상 이펙트와 상태 변경을 같은 프레임에 시작한다.

이펙트는 `PaintEffectPool`에서 재사용하며, 셀 크기와 기준 크기의 비율로 스케일을 맞춘다. 중단 또는 비활성화 시 `CompleteImmediately`와 남은 계획 적용을 통해 모델과 View가 어긋나지 않게 한다.

## 입력과 판정 순서

```text
커맨드 성공
→ 모델 최종 상태 적용
→ Undo/Clear 입력 잠금
→ 물감통 드래그/드롭 입력은 예약용으로 유지
→ 확산 View 재생
→ 예약 큐가 있으면 다음 물감통 실행
→ 예약 큐가 비면 StageClearChecker.Check
```

모델이 연출보다 먼저 최종 상태가 되기 때문에 Undo/Clear 잠금은 선택 사항이 아니라 일관성 규칙이다. 다만 다음 물감통 드래그는 즉시 커맨드로 실행하지 않고 예약 큐에 넣으면 안전하게 받을 수 있다. 예약 큐는 현재 연출이 끝난 뒤 FIFO로 실행되며, 마지막 예약까지 끝난 뒤에만 정답 판정을 수행한다.
