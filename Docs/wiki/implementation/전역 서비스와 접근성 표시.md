# 전역 서비스와 접근성 표시

## Overview

씬 사이에서 유지되는 기능은 선택 스테이지, 씬 전환, 설정 팝업, 사운드다. 색상 접근성은 별도의 표시 설정 컴포넌트가 팔레트와 심볼 여부를 이벤트로 배포한다. 규칙 상태와 표시 리소스를 분리해 같은 `PaintState`를 다른 색과 Sprite로 표현할 수 있다.

## 지속 싱글톤

`LazyPersistentSingleton<T>`는 최초 접근 시 기존 비활성 인스턴스까지 찾고, 없으면 새 GameObject를 만든다. 루트로 이동한 뒤 `DontDestroyOnLoad`를 적용하며 중복 인스턴스를 파괴한다. 현재 `StageRunContext`, `SceneTransitionManager`, `GameSettingsService`가 이를 사용한다.

`SoundManager`도 지속 싱글톤이지만 자체 `Instance`와 `Awake` 구현을 사용한다. 기능상 문제는 아니지만 전역 객체 생성 규칙이 두 종류라는 점은 유지보수 시 알아야 한다.

## 씬 전환과 설정 팝업

`SceneTransitionManager`와 `GameSettingsService`는 각각 `Resources/SceneTransitionUI`, `Resources/GameSettingsUI` 프리팹을 처음 필요할 때 생성한다. UI 연출은 UniTask로 DOTween 완료를 기다리고 객체 파괴 토큰으로 취소한다.

설정 팝업은 확인·취소 이벤트, 배경 차단, 표시·숨김 연출을 제공한다. 연속 전환 요청은 버전 번호와 활성 Tween 교체로 오래된 완료 콜백이 새 상태를 덮지 못하게 한다. 현재 코드에서 확인되는 범위는 팝업 골격이며 실제 설정 항목의 적용 연결은 아직 없다.

## 사운드

`SoundManager`는 `SoundLibrary`의 문자열 키로 BGM과 SFX를 찾는다. BGM은 같은 Clip이면 재시작하지 않고, SFX는 최소 3개의 AudioSource를 라운드로빈해 겹쳐 재생한다. BGM/SFX 볼륨은 별도로 `PlayerPrefs`에 저장한다.

현재 플레이는 스테이지 BGM, 물감통 사용, Undo, 전체 지우기 효과음을 호출한다. 키 상수는 `SoundKeys`에 모여 있어 호출부의 문자열 오타를 줄인다.

## 접근성 표시

`AccessibilityDisplaySettings`는 활성 `ColorPaletteSO`와 심볼 표시 여부를 보관하고 변경 이벤트를 발생시킨다. `CellView`, 물감통 View, 스테이지 미리보기는 이 설정을 구독해 즉시 다시 그린다.

`ColorPaletteSO`는 각 `PaintState`의 색과 `PaintVisualSet`, 각 `PaintType`의 기본색을 제공한다. 심볼 색은 sRGB를 선형 휘도로 변환해 검정·흰색 중 대비가 큰 쪽을 고른다. 프로젝트에는 기본, 적록 보정, 청황 보정 팔레트 에셋이 있다.
